# AI Kullanım Notları

## Proje
Gençlik Günlüğü - Blog Web Sitesi

## 1. Prompt
Üniversite öğrencileri ve gençler için kişisel gelişim, motivasyon ve günlük yaşam konularında beş blog yazısı başlığı öner.

**Amacı:** Blog sitemin konusunu ve içerik başlıklarını belirlemek.

## 2. Prompt
HTML kullanarak ana sayfa, içerikler sayfası ve hakkında sayfasından oluşan üç sayfalı bir blog sitesi oluşturmak için gerekli yapıyı öner.

**Amacı:** Web sitesinin sayfa yapısını oluşturmak.

## 3. Prompt
JavaScript kullanarak blog yazılarını başlıklarına göre arayan, sonuç sayısını gösteren ve temizle butonu bulunan bir arama sistemi oluştur.

**Amacı:** İçerikler sayfasına arama özelliği eklemek.

## Yapay Zekâ Önerilerinin Değerlendirilmesi

Önerilen HTML, CSS ve JavaScript kodlarını projemde kullandım. Kodları dosyalara eklemeden önce inceleyerek sayfaların ihtiyaçlarına uygun olmasına dikkat ettim. Renkleri ve içerikleri blogumun temasına göre düzenledim.

## Kod Açıklamaları

### Event Listener Nedir?
Event listener, kullanıcının yaptığı bir işlemi dinleyen JavaScript yapısıdır. Örneğin arama kutusuna yazı yazıldığında input olayı gerçekleşir ve arama sistemi çalışır.

### Filtreleme Koşulu Nedir?
Filtreleme koşulu, aranan kelimenin yazı başlığında bulunup bulunmadığını kontrol eder. Kelime başlıkta bulunuyorsa kart gösterilir, bulunmuyorsa gizlenir.
